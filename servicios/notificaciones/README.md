# Servicio de notificaciones

Alertas al operador cuando una corrida falla, termina o necesita atencion. Push a Android por FCM cuando hay internet, y WebSocket con reconexion en modo laboratorio, donde FCM no existe.

Es un consumidor de eventos: si se cae, la ejecucion y el monitoreo siguen operando (ASR-D3).

**Sostiene** ASR-D3.

**Historias** Sprint 2.
