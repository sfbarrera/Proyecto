# Servicio de procedimientos

Autoria y versionado de los procedimientos de prueba. Un procedimiento es una secuencia ordenada de pasos parametrizables; al modificarlo se crea una version nueva y la anterior queda consultable.

Los tipos de paso se **registran**, no se codifican en un condicional: por eso se puede agregar un tipo nuevo sin tocar el motor de ejecucion (ASR-M3).

**Sostiene** ASR-M3, ASR-S1, ASR-S3.

**Historias** HU-03.
