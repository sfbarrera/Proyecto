# Servicio de catalogo

Inventario de equipos del laboratorio: identificacion, interfaz de comunicacion, recurso VISA, driver asociado, capacidades declaradas, limites de seguridad y estado. Tambien lleva el registro de agentes.

Los limites de seguridad del equipo nacen aqui: todo lo que despues impida un comando fuera de envolvente se apoya en lo que se registre en este servicio.

**Sostiene** ASR-S1.

**Historias** HU-02.
